Как пользоваться гитом:

1. git pull (обновление директории);
2. vim filename.md / vim filename.txt (создание файла и запись); (выход из vim: esc :wq)
Тебе нужно записать условие билета в этот файл;
3. git add . (сохранение измений)
4. git commit -m "билет (название)"
5. git push / git push origin develop - (это если ругается на не точный путь)
После ждешь минут 5 или 10;
6. git pull (обновление директории);

Если еще есть время, тихонечко перепечатываешь из теримнала
cat filename.cpp
Если время поджимает, есть команда (cp - копирование)
Пример: cp(комнада) ~/task7.txt(откуда, путь) task_new.txt(куда, тоже путь)
В задачах обычно КОМЕНТАРИИ, когда будешь отправлять ИМ лучше ИЗБАВИТЬСЯ от них! 
Если возникнут трудности с гитом, ищи задачи в папках, там много чего есть. Удачи!
